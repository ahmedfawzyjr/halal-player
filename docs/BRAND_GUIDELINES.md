# Halal Player - Brand Guidelines

## Logo Files
- `logo.png` - Full logo (horizontal)
- `logo-icon.png` - App icon (square)

## Color Palette

### Primary Colors
| Name | Hex | RGB | Usage |
|------|-----|-----|-------|
| Halal Green | #4CAF50 | 76, 175, 80 | Primary brand, buttons, safe indicators |
| Dark Background | #1A1A1A | 26, 26, 26 | Main background (dark mode) |
| Dark Surface | #2A2A2A | 42, 42, 42 | Cards, panels (dark mode) |

### Light Mode Colors
| Name | Hex | RGB | Usage |
|------|-----|-----|-------|
| Light Background | #F5F5F5 | 245, 245, 245 | Main background |
| Light Surface | #FFFFFF | 255, 255, 255 | Cards, panels |

### Status Colors
| Name | Hex | Usage |
|------|-----|-------|
| Safe Green | #4CAF50 | AI allowed content |
| Warning Amber | #FFC107 | Blurred content |
| Blocked Red | #F44336 | Blocked content |

## Typography
- **Primary Font**: System default (Segoe UI on Windows)
- **Headings**: Medium weight, larger sizes
- **Body**: Regular weight

## Icon Style
- Material Design 3 icons
- Outlined style preferred
- 24dp standard size

## App Icon Sizes
- Windows: 256x256, 128x128, 64x64, 48x48, 32x32, 16x16
- Use logo-icon.png as base

## Usage Guidelines
1. Always maintain logo proportions
2. Minimum clear space: 1/4 of logo width
3. Don't modify logo colors
4. Use on dark backgrounds for best visibility
