# Models Directory
This folder contains AI model files (ONNX format).

## Required Models
- `nsfw.onnx` - OpenNSFW2 model for NSFW detection
- `nudenet.onnx` - NudeNet model for nude detection

## Download Instructions
1. Download OpenNSFW2 from: https://github.com/bhky/opennsfw2
2. Download NudeNet from: https://github.com/notAI-tech/NudeNet

Note: Models are not included due to size. You need to download them separately.
